# Programación Minecraft

A guide and toolkit for aspiring creators to build their own worlds in Minecraft using Ruby.

## Getting Started
Follow the steps in `doc/installation_guide.md`.

## Development
This project follows Test-Driven Development (TDD) principles.
Run tests using:
```bash
bundle exec rspec
```

### Build System
Support for Gradle has been added for JVM-based components (Minecraft).
Build using: `./gradlew build`
