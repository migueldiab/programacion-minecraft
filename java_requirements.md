# Java Requirements for Minecraft

Research conducted on November 24, 2026.

## Summary Table
| Minecraft Version(s) | Minimum Java Version | Recommended JDK |
|-----------------------|----------------------|-------------------|
| 1.18 - 1.20.4         | Java 17             | JDK 17            |
| 1.20.5 - 1.21.11      | Java 21             | JDK 21            |
| 26.1+ (Snapshots)     | Java 25             | JDK 25            |

## Key Findings
- **Stability:** Always aim for the version specified by Mojang. While higher versions often work (e.g., running 1.20.4 on Java 21), staying within the tested bounds prevents unexpected behavior.
- **Development:** For building plugins or mods for recent versions (1.20.5+), **JDK 21** is the current standard.
- **Sources:** Verified via Minecraft Wiki and community support providers.
